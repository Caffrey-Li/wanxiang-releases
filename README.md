# 万象小助手

万象小助手是一个 macOS 应用（带菜单栏面板），在本机统计各家 AI 工具的用量与额度，整理对话、帮你把对话交接到另一个工具继续，并清理 AI 工具留下的缓存。数据只存在你的电脑上。

这个仓库只用来发布安装包，不包含源码。

## 下载

**[下载最新版（Wanxiang.dmg）](https://github.com/Caffrey-Li/wanxiang-releases/releases/latest/download/Wanxiang.dmg)**

- 支持 macOS（Apple 芯片和 Intel 通用）。
- 安装包经过 Apple 公证，打开后把「万象小助手」拖进「应用程序」即可。
- 装好以后，应用会自动检查更新，在顶栏提示新版本。

历史版本和更新说明见 [Releases](https://github.com/Caffrey-Li/wanxiang-releases/releases)。
